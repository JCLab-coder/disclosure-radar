## P2-1

```
관심 종목에 공시가 올라오면 텔레그램으로 보내 줘. 관심 종목은 삼성전자, 카카오, 에코프로비엠 세 개로 시작하자. .env 에 TELEGRAM_BOT_TOKEN 과 TELEGRAM_CHAT_ID 를 넣어 뒀어. 의존성은 추가하지 말고, 중복 처리는 나중에 할 거니까 지금은 한 번 실행하면 한 번 보내기만 하면 돼. 만들고 실제로 한 번 보내서 확인해 줘.
```

왜 이렇게 썼나 — 위키는 한마디도 말하지 않는다. 규칙 파일만으로 결정이 남는지 본다. 뒷장(중복) 소재는 범위 밖이라고 미리 말한다

## P2-5

```
이번 일로 알게 된 게 있어. 위키의 결정에는 내가 정한 것과 너희가 작업하다 고른 것이 섞여 있는데, 다음 세션은 둘을 구분하지 못해서 너희가 고른 것까지 내 결정처럼 지키려고 했어. 결정 페이지마다 누가 정했는지(사용자, 또는 AI가 고른 기본값)를 적고, 지금 있는 페이지들도 대화와 커밋에서 확인되는 경위대로 고쳐 줘. 그리고 CLAUDE.md 와 AGENTS.md 의 규칙을 고쳐서, 사용자가 정한 결정은 바꾸기 전에 묻고, AI가 고른 기본값은 이유를 말하고 바꿔도 되게 해 줘. 지어내지 말고 확인되는 것만.
```

왜 이렇게 썼나 — 사고에서 규칙을 만든다. 누가 정했는지라는 칸 하나가 결정의 무게를 가른다
