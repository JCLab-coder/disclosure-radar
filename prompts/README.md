# 장마다 클로드코드와 코덱스에 입력한 지시

장마다 파일 하나. 사람이 실제로 친 지시를 순서대로, 원문 그대로 담았다. 코드 블록 안의 문장은 손대지 않았다.
각 지시 아래의 '왜 이렇게 썼나'는 그 문장을 고른 이유다.

| 파일 | 장 | 끝난 시점의 태그 |
|---|---|---|
| `ch01.md` | 1장. 위키 없이 시작하면 | `ch01` |
| `ch02.md` | 2장. 결정은 대화에 남지 않는다 | `ch02` |
| `ch03.md` | 3장. 위키에 없는 것은 추측한다 | `ch03` |
| `ch04.md` | 4장. 같은 실수를 두 번 하지 않으려면 | `ch04` |
| `ch05.md` | 5장. 비밀은 위키에 적지 않는다 | `ch05` |
| `ch06.md` | 6장. 위키를 지키는 법 | `ch06` |
| `ch07.md` | 7장. 옵시디언으로 본다 | `ch07` |
| `ch08.md` | 8장. 6개월 뒤 위키가 망가지는 방식 | `ch08` |
| `ch09.md` | 9장. 내 업무 위키로 옮긴다 | `ch09` |

지시 안에 키나 토큰을 붙여 넣지 않는다. 대화 기록에 그대로 남는다. `.env` 에 두고 ".env 에 있어"라고만 말한다.
