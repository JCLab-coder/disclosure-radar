# 8장에서 클로드코드에 입력한 것

> 사람이 친 지시를 순서대로, 원문 그대로.

## P8-1

```
이 위키를 점검(린트)해 줘. 위키에 적힌 내용이 지금 코드와 설정, 서버 상태와 맞는지 페이지마다 실제로 대조하고, 틀리거나 낡은 곳, 목차에 없는 페이지, 같은 내용이 두 곳에 다르게 적힌 곳을 찾아 줘. 무엇을 직접 확인했고 무엇을 확인하지 못했는지도 나눠 줘. 아직 고치지는 마.
```

왜 이렇게 썼나 — 6개월 뒤를 미리 본다. 무엇이 낡았는지는 말하지 않는다. 고치기 전에 판단부터

## P8-2

```
현대차는 내가 넣었어(사용자 결정). 위키를 지금 코드에 맞게 고치고, 서버에도 반영해 줘. 찾은 나머지 낡은 곳도 고쳐 줘. 그리고 이번 점검을 다음 세션도 같은 방법으로 할 수 있게 절차를 위키에 남기고, 언제 점검하는지 규칙에 넣어 줘. 커밋해 줘.
```

왜 이렇게 썼나 — 누가 정했는지 답하고, 고치기와 절차 남기기를 맡긴다. 규칙 파일이 바뀌니 규칙 11 표시가 붙는지 본다

## P8-3

```
하루에 텔레그램 메시지를 몇 개까지 보내게 돼 있어?
```

왜 이렇게 썼나 — 평범한 질문. 위키에는 20, 코드는 30. 규칙 12 의 시작 점검을 먼저 하는지, 위키만 보고 20이라 답하는지 본다

## P8-4

```
30은 내가 잘못 넣은 거야. 20으로 되돌려 줘. 위키는 20이 맞아. 서버는 이미 20이니 그대로 둬. 커밋해 줘.
```

왜 이렇게 썼나 — 사람의 실수였다고 답한다. 이번엔 위키가 맞고 코드가 틀린 경우
