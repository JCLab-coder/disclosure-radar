# 텔레그램 전송에 node-telegram-bot-api를 쓴다

- 정한 날: 2026-10-03
- 누가 정함: 사용자
- 상태: 유지
- 관련: [[index]], [[log]], [[watchlist-telegram]], [[file-structure]]

## 결정

- `node-telegram-bot-api`를 의존성으로 추가하고, `notify.js`의 직접 `fetch` 호출을 라이브러리의 `sendMessage()`로 바꾼다. (사용자)
- 설치 버전 2.1.0의 `Api` 객체로 전송만 한다. 기존처럼 실패 시 재시도 없이 종료하도록 `maxRetries: 0`으로 설정한다. (AI 기본값)
- 한 번 실행에 모아 보내기, 4096자 초과 시 나누기, 링크 미리보기 끄기, 관심 종목 필터와 `.env` 설정은 기존대로 유지한다. (기존 동작 유지)

## 이유

- 사용자가 텔레그램 전송 코드를 더 깔끔하게 만들기 위해 라이브러리 사용을 요청했다.
- [[watchlist-telegram]]의 의존성을 추가하지 않는다는 이전 결정을 이번 요청으로 변경한다.

## 근거

- 2026-10-03 사용자 요청 원문: "텔레그램 보내는 코드를 node-telegram-bot-api 라이브러리로 바꿔 줘. 그게 더 깔끔할 것 같아."
- `Api` 사용과 재시도 비활성화는 수신 없이 공시를 한 번 보내고 실패 시 종료하는 기존 실행 방식에 맞춰 AI가 골랐다.

## 확인

- 실제 라이브러리를 사용하고 HTTP 응답만 가짜로 대체하여, 공시 3건을 메시지 1개로 보내기, 60건 분할(각 4096자 이하), 관심 종목 0건일 때 미전송, API 오류·네트워크 오류 시 재시도 없이 종료, 설정 누락 시 요청 없이 종료를 확인했다. 실제 텔레그램 전송은 하지 않았다.
- 종목코드 필터, 분할 시 공시 누락·중복 없음, 링크 미리보기 비활성화도 확인했다. `node --check notify.js`와 `git diff --check`를 통과했다.
