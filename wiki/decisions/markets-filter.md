# 공시 목록은 유가·코스닥만 보여 준다

- 정한 날: 2026-10-03
- 상태: 유지
- 관련: [[index]], [[log]]

## 결정

`index.js` 의 `MARKETS = ['Y', 'K']` 는 일부러 코넥스(N)·기타법인(E)을 뺀 것이다. 화면에는 유가증권시장(Y)과 코스닥(K) 공시만 보여 준다.

## 이유

- 사용자가 보는 종목이 유가증권·코스닥에만 있다.
- 다 섞으면 목록이 너무 길어진다.

## 경위

"공시가 적게 나온다"는 말에 필터를 넓혔다가, 사용자가 되돌리라고 했다. 이 이유가 다음 세션에 전해지지 않아 Claude Code 와 Codex 가 같은 결정을 두 번 뒤집었다. 그래서 이 페이지를 남긴다.

2026-10-03 에 "DART 사이트보다 공시가 적게 나온다"는 말이 다시 나왔다. 2026-10-02 공시를 확인해 보니 전체 771건을 모두 받았고 중복도 없었다(유가 307, 코스닥 266, 기타 194, 코넥스 4). 건수 차이는 필터로 빠지는 기타·코넥스 198건이었다. 사용자가 필터를 그대로 두기로 다시 정했다.

## 앞으로

- 공시 건수가 DART 사이트보다 적다는 말이 나와도 이 필터는 그대로 둔다. 전체 건수와 유가·코스닥 건수는 출력 첫 줄에 같이 나온다.
- 먼저 유가·코스닥 안에서 빠진 공시가 있는지 확인한다.
- 필터를 바꿔야 할 것 같으면 바꾸기 전에 사용자에게 먼저 물어본다.
