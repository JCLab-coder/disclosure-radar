# 파일을 역할별로 셋으로 나눈다

- 정한 날: 2026-10-03
- 누가 정함: 사용자 (처음에는 AI 기본값이었고, 2026-10-03 사용자가 이유를 듣고 유지하기로 확정했다)
- 상태: 유지
- 관련: [[index]], [[log]], [[watchlist-telegram]]

## 결정

- 코드는 세 파일로 둔다.
  - `dart.js`: 공시 조회(OpenDART 공시검색 API 호출)와 공용 함수. 직접 실행하지 않는다.
  - `index.js`: 공시 목록 출력. `node index.js [YYYYMMDD]`.
  - `notify.js`: 관심 종목 공시 텔레그램 알림. `node notify.js [YYYYMMDD]`.
- 공시 조회 코드를 `notify.js` 안으로 다시 합치지 않는다.
- 헷갈리지 않도록 각 파일 맨 위 주석에 자기 역할과 다른 두 파일의 역할을 적는다.

## 이유

- `notify.js` 는 불러오기만 해도 `main()` 이 실행된다. 조회 코드를 `notify.js` 에 두고 `index.js` 가 그것을 불러오면, 목록만 보려고 `node index.js` 를 실행해도 텔레그램 알림이 나간다.
- 그렇다고 `index.js` 에 조회 코드를 복사하면 같은 코드가 두 곳에 생겨, 고칠 때 양쪽을 다 고쳐야 한다.

## 경위

- `dart.js` 로 나눈 것은 [[watchlist-telegram]] 작업 때 이전 세션(에이전트)이 고른 것이고, 사용자가 정한 것은 아니었다.
- 2026-10-03 사용자가 "파일이 셋이라 헷갈린다"며 조회 코드를 `notify.js` 로 합치자고 했다. 위 이유를 듣고 세 파일 구조를 유지하고 주석과 위키로 역할을 밝히기로 했다(안 A).
