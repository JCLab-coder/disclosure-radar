# .env 와 node_modules 는 커밋하지 않는다

- 정한 날: 2026-10-02 (`wiki/.obsidian/` 과 위키에 비밀값 적지 않기는 2026-10-03)
- 누가 정함: 항목마다 다르다. 각 항목 끝 괄호에 적었다. `.env` 는 2026-10-03 사용자가 ".env 를 커밋하지 않는 건 내가 정했어"라고 확인해 사용자로 고쳤다(처음에는 커밋 `3515f73` 만 있어 "확인 안 됨"이었다).
- 상태: 유지
- 관련: [[index]], [[log]], [[api-keys]], [[railway-deploy]]

## 결정

- `.gitignore` 에 `.env` 와 `node_modules/` 를 넣어 커밋에서 뺀다. (`.env` 는 사용자. `node_modules/` 는 같은 커밋에서 정했지만 사용자가 따로 말하지 않았다. 확인 안 됨.)
- 키 같은 비밀값은 위키에 적지 않는다. 위키에는 이름과 받는 곳만 적는다([[api-keys]]). 이 규칙을 `CLAUDE.md`·`AGENTS.md` 10 에 넣었다. (사용자)
- `wiki/.obsidian/` (옵시디언 개인 설정)도 `.gitignore` 에 넣어 커밋하지 않는다. (사용자)

## 이유

- `.env` 에는 API 키(`OPENDART_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `OPENROUTER_API_KEY`)가 들어 있다. `dart.js` 가 `process.loadEnvFile` 로 이 파일을 읽는다.
- `node_modules/` 는 설치하면 다시 생기는 파일이라 저장소에 둘 필요가 없다.
- 위키도 git 에 커밋되고 저장소는 나중에 공개한다. 공개 전에 지워도 커밋 기록에 남는다.
- `wiki/.obsidian/` 은 사용자의 옵시디언 개인 설정이라 프로젝트 결정이 아니다.

## 앞으로

- API 키 같은 비밀값은 코드·커밋·위키에 넣지 않고 `.env`(로컬)와 서버 변수([[railway-deploy]])에만 둔다.

## 덧붙임

- 2026-10-03 사용자가 다른 컴퓨터에서 봇을 돌릴 수 있게 "서버에 넣은 키 네 개를 위키에 정리해 줘"라고 요청했다. AI 가 위 이유로 값은 적지 않고 이름과 받는 곳만 적는 안(A)을 제안했고, 사용자가 A 로 하라고 했다. 그때 이 페이지의 "누가 정함"도 확인했다.
