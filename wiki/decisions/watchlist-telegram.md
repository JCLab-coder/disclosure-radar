# 관심 종목 공시를 텔레그램으로 보낸다

- 정한 날: 2026-10-03
- 상태: 유지
- 관련: [[index]], [[log]], [[markets-filter]], [[env-not-committed]]

## 결정

- `notify.js` 가 그날(기본: 오늘, KST) 공시 중 관심 종목 공시를 텔레그램으로 한 건에 메시지 하나씩 보낸다. 사용법은 `node notify.js [YYYYMMDD]`.
- 관심 종목은 삼성전자(005930), 카카오(035720), 에코프로비엠(247540) 세 개로 시작한다. `notify.js` 의 `WATCHLIST` 에 있다.
- 관심 종목은 회사 이름이 아니라 종목코드(`stock_code`)로 맞춘다.
- 중복 처리는 아직 하지 않는다. 한 번 실행하면 그날 공시를 한 번 보낸다. 다시 실행하면 같은 공시를 또 보낸다. 중복 처리는 나중에 하기로 했다.
- 의존성은 추가하지 않는다. 텔레그램 Bot API 는 Node 내장 `fetch` 로 부른다.
- 텔레그램 비밀값은 `.env` 의 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` 에 둔다.
- 공시 조회 코드는 `dart.js` 로 옮겨 `index.js` 와 `notify.js` 가 같이 쓴다.

## 이유

- 종목코드로 맞추는 이유: 이름에 "카카오"가 들어가면 카카오뱅크·카카오페이·카카오페이증권이, "삼성전자"가 들어가면 삼성전자서비스씨에스가 같이 걸린다. 2026-09-29 ~ 10-02 공시에서 실제로 확인했다.
- 중복 처리·의존성은 사용자가 지금은 하지 말라고 했다.

## 확인

- 2026-10-03 은 토요일·개천절이라 공시가 0건이었고, 아무것도 보내지 않았다.
- `node notify.js 20261001` 로 관심 종목 공시 5건(에코프로비엠 2, 삼성전자 2, 카카오 1)을 실제로 보냈고, 텔레그램 API 가 모두 `ok` 로 응답했다. 같은 날 카카오뱅크 등은 섞이지 않았다.
