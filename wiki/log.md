# 변경 기록

위키에 무엇을 언제 바꿨는지 적는다. 최신이 위로 온다. 목차는 [[index]].

## 2026-10-03

- [[watchlist-telegram]] 의 "한 건에 메시지 하나"(AI 기본값)를 사용자 요청대로 "한 번 실행에 메시지 하나"(사용자)로 바꿨다. 텔레그램 4096자 한도를 넘을 때만 나누는 것은 AI 기본값으로 적었다. 목차 요약도 고쳤다.
- [[watchlist-telegram]] 에서 확인 안 됨이던 항목을 사용자 확인대로 고쳤다. 종목 세 개와 `.env` 비밀값은 사용자, 종목코드 매칭과 한 건에 메시지 하나는 AI 기본값이다. 날짜 기본값과 사용법은 아직 확인 안 됨이다. 근거 원문은 줄이지 않고 그대로 적는다는 규칙을 `CLAUDE.md`·`AGENTS.md` 규칙 3 과 목차의 쓰는 규칙에 넣었다.
- 결정 페이지마다 누가 정했는지(사용자 / AI 기본값 / 확인 안 됨)를 적었다. 대화 원문과 커밋으로 확인되는 것만 "사용자"로 적었다. [[markets-filter]]·[[file-structure]] 는 사용자, [[env-not-committed]] 는 확인 안 됨, [[watchlist-telegram]] 은 항목별로 적었다. 목차와 쓰는 규칙에도 반영했고, `CLAUDE.md`·`AGENTS.md` 규칙 2·3 을 고쳤다. 사용자 결정은 묻고 바꾸고, AI 기본값은 이유를 말하고 바꿔도 된다. 확인 안 됨은 사용자 결정처럼 다룬다.
- [[file-structure]] 를 추가하고 목차에 넣었다. 세 파일 구조를 유지하기로 한 결정이다. [[watchlist-telegram]] 에 `dart.js` 분리가 처음엔 이전 세션의 선택이었고 이번에 사용자가 확정했다는 덧붙임을 달았다.
- [[watchlist-telegram]] 를 추가하고 목차에 넣었다. 관심 종목 텔레그램 알림(`notify.js`)과 공시 조회 공용 코드(`dart.js`)를 만든 결정이다.
- [[markets-filter]] 경위에 다시 확인한 내용을 덧붙이고 목차에도 반영했다. 유가·코스닥 안에서 빠진 공시는 없었고, 사용자가 필터를 그대로 두기로 했다.
- 위키를 시작했다. `index.md`, `log.md` 를 만들었다.
