# disclosure-radar 위키

이 프로젝트에서 정해진 결정과 그 이유를 남기는 곳이다. 작업을 시작하기 전에 이 목차와 관련 페이지를 먼저 읽는다.

- 변경 기록: [[log]]

## 결정 (decisions/)

괄호는 누가 정했는지다. 사용자 / AI 기본값 / 확인 안 됨. 다루는 법은 `CLAUDE.md`·`AGENTS.md` 규칙 2.

- [[markets-filter]] (사용자): 공시 목록은 유가·코스닥만 보여 준다. 건수가 적다는 이유로 넓히지 않는다. 2026-10-02 공시의 유가·코스닥 내 누락이 없음을 확인했다.
- [[watchlist-telegram]] (항목마다 다름): 관심 종목(삼성전자·카카오·에코프로비엠) 공시를 `notify.js` 가 텔레그램으로 보낸다. 종목코드로 맞추고, 한 번 실행에 메시지 하나로 모아 보낸다(4096자 넘으면 나눔). 중복 처리는 아직 없다.
- [[telegram-library]] (사용자, 설정은 AI 기본값): 텔레그램 전송은 `node-telegram-bot-api`의 `sendMessage()`를 쓴다. 의존성 추가 금지 결정을 사용자 요청으로 변경했다.
- [[disclosure-summary]] (항목마다 다름): 관심 종목 공시마다 원문(OpenDART `document.xml`)을 OpenRouter 저가 모델(`google/gemini-2.5-flash-lite`)로 세 줄 요약해 메시지에 넣는다. 원문 6000자·출력 300 토큰 제한. 요약이 실패하면 요약 없이 보낸다.
- [[file-structure]] (사용자): 코드는 `dart.js`(공시 조회)·`index.js`(목록 출력)·`notify.js`(텔레그램 알림) 셋으로 둔다. 조회 코드를 `notify.js` 로 합치지 않는다.
- [[env-not-committed]] (확인 안 됨): `.env`(API 키)와 `node_modules/`는 커밋하지 않는다.

## 자료 (references/)

결정이 아니라 작업하다 알아낸 자료다. 출처와 확인한 날짜가 적혀 있다.

- [[opendart-document-api]]: OpenDART 공시서류원본 API(`document.xml`)의 응답 형식. zip 안에 `<접수번호>.xml` 하나, UTF-8, HTML 형식과 dart4 XML 형식이 있다. 호출 한도는 오픈API 전체 합쳐 하루 20,000건(공식 FAQ, 2026-10-03 확인), 넘으면 오류 코드 `020`.
- [[openrouter-models]]: OpenRouter 저가 모델과 요금(2026-10-03 기준), 요약에 쓰는 `chat/completions` 호출.

## 쓰는 규칙

- 결정 하나에 페이지 하나를 `wiki/decisions/<이름>.md` 로 만든다. 무엇을 정했는지, 누가 정했는지(사용자 / AI 기본값 / 확인 안 됨), 왜 그랬는지, 언제 정했는지, 근거(커밋·대화)를 적는다. 한 페이지 안에서 항목마다 다르면 항목 끝 괄호에 적는다. 근거로 남기는 대화 원문은 줄이지 않고 그대로 적는다.
- 실제로 정해진 것만 적는다. 추측이나 아직 정하지 않은 안은 결정 페이지로 만들지 않는다.
- 페이지끼리는 `[[페이지이름]]` 으로 잇는다.
- 페이지를 추가하거나 고치면 이 목차와 [[log]] 를 함께 고친다.
- "확인" 칸에는 실제로 돌린 명령과 범위(몇 건 중 몇 건, 무엇과 무엇을 비교했는지)만 적는다. 확인하지 않은 것은 확인하지 않았다고 적는다.
- 결정이 아닌 자료(외부 API 형식, 모델과 요금 등)는 `wiki/references/<이름>.md` 로 따로 만든다. 출처 주소와 확인한 날짜를 적는다.
- 위키에 있는 것을 물으면 근거 페이지를 달아 답하고, 위키에 없는 것은 없다고 말한다.
- 결정을 뒤집을 때는 페이지를 지우지 않고, 바뀐 내용과 이유를 그 페이지에 덧붙인다.
